# Yemeni Delights

A responsive, bilingual restaurant website built with HTML, CSS and JavaScript. No runtime dependencies, external fonts, analytics, cookies or data collection.

## Run

Use Node.js 22 or later. Run `npm run dev` in this directory; the server listens on port 3000 (override with `PORT`).

## Before publication

The business name, location and Facebook URL came from the supplied brief and have not been independently verified. Google and Facebook requests were blocked by the cloud network policy. All food images are AI-created illustrative assets; the dishes are an introduction to Yemeni cuisine, not a verified restaurant menu. No invented prices, opening times, customer reviews, phone number or email are presented. Directions open Red Sea Mall, not an independently verified restaurant pin.

Replace illustrative dish data and photography with the confirmed menu and authorized business images. Confirm the Arabic brand name, exact mall unit, hours, email, phone, delivery and ordering links. Add these details before enabling ordering or reservations. The current contact action opens the supplied Facebook page.

Edit bilingual copy in `data-en`/`data-ar` attributes and the `dishes` array in index.html. Language selection lives in memory only. Site is English first with an Arabic RTL toggle. Assets are local; no external image requests are needed.
